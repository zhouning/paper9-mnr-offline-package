# 内置乡镇空间参考

`xiangzhen_zhongning.gpkg` 是 Paper9v2.3 中宁县 DLTB-only 包的行政参考，图层名为
`admin_reference`，包含中宁县 13 个乡镇面，行政区代码为 `640521`。文件坐标系为
`EPSG:4326`，来源、范围和校验值记录在 `MANIFEST_ZHONGNING.json`。

该文件仅用于乡镇名称和空间归属，不代替法定行政区划成果，也不生成生态保护红线、
永久基本农田或交换锁定条件。

## 东兴区、璧山区历史参考

`xiangzhen_dongxing_bishan.gpkg` 从客户提供的全国 `xiangzhen.shp` 中按县名筛出，包含：

- 四川省内江市东兴区：29 个乡镇/街道面；
- 重庆市璧山区：15 个乡镇/街道面。

图层名为 `admin_reference`，坐标系为 `EPSG:4326`，名称字段为 `XZQMC`。

该数据仅用于乡镇中文名称和空间归属，不参与坡度计算、生态红线、永久基本农田或耕地/林地交换锁定。源数据日期为 2021-06-22，且没有乡镇行政代码；输出中的 `XZQDM` 是运行时根据 DLTB 最大重叠关系关联的代码，必须结合客户 2025 年行政区资料复核。

原始“璧山区青杠街道”为两个相距约 200 公里的分离面，其中一个位于 `107.49E, 30.76N`，明显不在璧山区。内置参考层已移除该离群分离面，只保留璧山区主体范围内的青杠街道面；修复范围和最终 SHA-256 记录在 `MANIFEST.json`。
